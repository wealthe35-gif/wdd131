FitLife: Fitness and Healthy Living

WDD 131 Website Planning Document

1. Site Name

Proposed Name: FitLife (FitLife: Fitness and Healthy Living)

Reason: I chose this name because it is short, energizing, and immediately communicates the goal of making fitness and healthy habits a sustainable part of everyday life for beginners.

Optional Domain: Fitlifebeginners.org

2. Site Purpose

FitLife provides a welcoming, friendly hub for exercise and healthy living. The website will feature three main pages: a Home page introducing the site, a Workouts page showcasing simple beginner exercise routines, and a Healthy Living page sharing practical guidance on nutrition, hydration, sleep, and daily wellness habits along with an interactive goal/contact form.

3. Scenarios

  • I am new to working out and have no gym equipment what simple beginner exercises can I start doing at home?
  • How much water should I drink each day, and what are easy habits for eating healthier and sleeping better?
  • How can I build a simple weekly fitness routine or send a question about getting started?

4. Color Schema

This planning document uses an energetic, fresh fitness color palette:

Primary Color: #1B4332 (Forest Green)
Used for the header, footer, navigation bar, and main section headings.
Accent Color: #FF7B00 (Energetic Orange)
Used for buttons, borders, call to action highlights, and active links.
Background / Text: #F4F9F4 / #1F2933
Used for clean page backgrounds, content cards, and dark readable text.

5. Typography

  • Heading Font: Montserrat — Used for the site title, navigation menu, and section headings (h1, h2, h3) to create a bold, modern athletic look.
  • Body Font: Open Sans — Used for paragraphs, workout instructions, lists, and form labels for high readability on both mobile and desktop screens.
